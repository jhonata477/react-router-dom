# 🎬 CineFlix

Uma plataforma de entretenimento desenvolvida com React, Tailwind CSS e consumo de API pública. O CineFlix permite explorar filmes, visualizar capas, avaliações e informações dos títulos.

## 📌 Sobre o projeto

O CineFlix foi desenvolvido como projeto acadêmico para praticar desenvolvimento front-end, criação de componentes, navegação entre páginas e consumo de APIs.

## 🚀 Funcionalidades

- Página inicial com filmes em destaque.
- Catálogo de títulos.
- Pesquisa de títulos.
- Navegação entre páginas.
- Exibição de capas, títulos e avaliações.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- Tailwind CSS
- React Router DOM
- Vite
- API pública Studio Ghibli

## 🌐 API utilizada

[Studio Ghibli API](https://ghibliapi.vercel.app/films)

A API fornece informações sobre filmes, incluindo títulos, imagens, datas de lançamento, sinopses e avaliações.

## 💻 Como executar o projeto

1. Clone o repositório:

```bash
git clone COLE_AQUI_O_LINK_DO_GITHUB
```

2. Entre na pasta do projeto:

```bash
cd react-router-dom
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Abra o endereço indicado no terminal, geralmente:

```text
http://localhost:5173
```
